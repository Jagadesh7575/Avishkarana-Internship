# Student Task Manager

A responsive Student Task Manager website created using HTML, CSS, and JavaScript.

## Features
- Add new tasks
- View tasks in a list
- Delete tasks
- Responsive design

## Topics Covered
- HTML structure and forms
- CSS styling and media queries
- JavaScript DOM manipulation

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Folder Structure
- `index.html`: The main HTML document
- `style.css`: The stylesheet for the application
- `script.js`: The JavaScript logic for task management
- `README.md`: Project documentation

## How to Run
1. Open the `Day_3-8` folder.
2. Double-click on `index.html` to open it in your web browser.

## Future Improvements
- Add task completion status
- Save tasks to local storage
